# 🎭 Nightlife Pass - Gestor de Listas para Boliches

Aplicación web rápida para control de accesos en eventos y boliches.

## Funcionalidades
- Registro de invitados por RPP, Product Owner o Casa.
- Filtro por listas Free, Cumpleaños y Descuento.
- Control de horario límite para accesos Free.
- Buscador rápido por Nombre, DNI o Teléfono para puerta.
- Marcado de ingreso instantáneo (tachar al ingresar).

## Deploy
Esta app está configurada para desplegarse automáticamente en **Netlify**.
